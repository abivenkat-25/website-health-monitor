WEBSITE HEALTH MONITOR - FLASK VERSION

1. Install Flask:
   py -m pip install flask

2. Open Command Prompt in this folder.

3. Run:
   py app.py

4. Open this address in your browser:
   http://127.0.0.1:5000

5. Enter one or more URLs and click Check Website.
   Click Download CSV to download the report.

Notes:
- monitor_report.csv is created automatically after the first check.
- Keep the terminal window open while using the local website.
- Stop the local server with Ctrl+C in the terminal.
- This is a local learning project; do not expose it publicly without
  additional security review.
